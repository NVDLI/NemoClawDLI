# Support

## Project status

This course repository is approved for public release. It provides static course material, not a
repository-operated runtime service or a support SLA.

Maintainers support the latest tagged release on a best-effort basis. Older
releases remain available for reproducibility but receive no promised fixes. A security advisory
may name a wider affected range and takes precedence over this default.

## Where to ask

- Actionable course, documentation, accessibility, build, or runtime defect: structured Issue.
- Question, learning friction, or early idea: Discussion after that feature is enabled.
- Proposed code change: Issue first, then a pull request following [`CONTRIBUTING.md`](CONTRIBUTING.md).
- General product security question from an NVIDIA employee: [#ask-security](https://nvidia.slack.com/archives/CAHCG5005).
- Vulnerability, credential, private URL, or exploit path: private route in [`SECURITY.md`](SECURITY.md).
- Abusive project content: private platform route in [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

Include the affected release or commit, page or file, environment, expected result, observed
result, and a minimal reproduction. Never include secrets or private deployment details.

## Response and lifecycle

Triage is best-effort. No response or resolution deadline is promised. Maintainers may close
reports that cannot be reproduced, fall outside the current release surface, duplicate existing
work, or lack information after a reasonable request.

Breaking changes and retirement decisions require an Issue, migration or replacement guidance,
and a release note before the affected supported release changes. If maintenance ends, the README
and `RELEASE_STATUS.json` must say so before the repository is archived or made read-only.
