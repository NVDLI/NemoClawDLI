Protección de agentes con OpenShell y NemoClaw

Resumen

Los agentes modernos están por todas partes y parten de una idea sencilla: un modelo conectado a herramientas, memoria y una decisión de enrutamiento que se repite hasta completar la tarea. Este curso comienza construyendo ese sistema desde cero y después conecta sus piezas con frameworks actuales, utilizados tanto por profesionales del software como por personas sin formación técnica. Avanzarás desde una única llamada a una API hasta la coordinación de agentes, la recuperación fundamentada, la planificación profunda y la implementación segura con OpenClaw y NemoClaw™ de NVIDIA.

1 Confirma las rutas de modelos a continuación. El chat y los embeddings usan de forma predeterminada los modelos de build.nvidia.com. Puedes cambiar el modelo y el endpoint de cada ruta según el rendimiento que necesites.
2 Sigue los módulos en orden para recorrer la ruta predeterminada o abre directamente la tarea que necesites. Cada página termina con un artefacto activo en el navegador y deja disponible su JavaScript para que puedas inspeccionarlo y adaptarlo.
3 Para los módulos posteriores, crea un launchable de NemoClaw. Aloja el stack de OpenClaw dentro de OpenShell definido por el blueprint de NemoClaw. El stack de servicios usa CPU y endpoints de modelos alojados, así que puedes reproducir los ejercicios localmente sin GPU.

Objetivos de aprendizaje

Al concluir el curso, sabrás:

  • Construir un bucle básico de agente e identificar sus componentes centrales.
  • Implementar uso confiable de herramientas y llamadas de función en un sistema de agentes.
  • Diseñar y coordinar sistemas multiagentes con patrones estructurados de enrutamiento.
  • Usar OpenShell para configurar identidades de agentes y garantizar operaciones seguras en sandbox.
  • Implementar y administrar agentes autónomos mientras creas bibliotecas persistentes de skills.

Cómo introducir tu clave de API

El navegador guarda las rutas de chat y embeddings entre lecciones y envía cada clave solo al endpoint seleccionado. Usa una ruta personalizada únicamente si dispones de un endpoint HTTPS accesible.

Cómo explorar el material

El orden de los módulos ofrece un camino guiado, pero cada página también funciona de forma independiente. En el recorrido completo, cada módulo aprovecha el anterior: el bucle ejecutado en navegador se convierte en un flujo de trabajo de alcance controlado; este flujo de trabajo pasa a un runtime de agente persistente; y el alcance mayor del runtime justifica el límite impuesto por el sistema operativo. Empieza por la tarea que necesites. Cada página termina en un artefacto activo y mantiene disponible el código de soporte. Puedes modificar los ejemplos en el navegador, alojarlos por tu cuenta o proporcionar este repositorio como contexto a un agente de código para una implementación o aplicación local.
