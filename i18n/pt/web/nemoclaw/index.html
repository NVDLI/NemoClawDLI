Proteção de Agentes com OpenShell e NemoClaw

Resumo

Agentes modernos estão por toda parte e partem de uma ideia simples: um modelo conectado a ferramentas, memória e uma decisão de roteamento que continua em execução até concluir a tarefa. O curso começa com a construção desse sistema do zero e liga cada etapa aos frameworks usados por profissionais de software e por pessoas sem formação técnica. Você avançará de uma chamada de API para coordenação entre agentes, recuperação fundamentada, planejamento profundo e implantação segura com NVIDIA OpenClaw e NemoClaw™.

1Confirme as rotas de modelo abaixo. Chat e embeddings usam build.nvidia.com por padrão. Durante um evento de capacidade, configure uma vez o endpoint de chat do Brev fornecido pelo instrutor; a rota independente de embeddings permanece inalterada. Ative o modo iframe somente com o endpoint de chat padrão.
2O curso completo está disponível em português. As doze aulas mantêm a mesma sequência, os mesmos exercícios e os mesmos limites técnicos da versão canônica.
3Para usar o stack de agentes nos Módulos 3 e 4, crie o launchable do NemoClaw quando o curso solicitar. Ele hospeda o stack OpenClaw em OpenShell definido pelo blueprint do NemoClaw. Os serviços do curso usam CPU e endpoints de modelos hospedados; portanto, os exercícios não exigem que o estudante gerencie uma GPU.

Objetivos de aprendizagem

Ao concluir o curso, você saberá:

  • Construir um ciclo básico de agente e identificar seus componentes centrais.
  • Implementar uso confiável de ferramentas e chamadas de função em um sistema de agentes.
  • Projetar e coordenar sistemas multiagente com padrões estruturados de roteamento.
  • Desenvolver pipelines automatizados de avaliação para medir desempenho e confiabilidade.
  • Usar o OpenShell para configurar identidades de agentes e garantir operações seguras em sandbox.
  • Implantar e gerenciar agentes autônomos enquanto cria bibliotecas persistentes de skills.

Como informar sua chave de API

O navegador salva as rotas de chat e embeddings em localStorage; uma única configuração vale para todas as aulas e abas. O navegador envia cada chave salva somente ao endpoint selecionado. Use um endpoint de chat personalizado apenas quando o instrutor o fornecer. As rotas de chat do Brev exigem um túnel HTTPS público para a porta 5000; túneis privados não aceitam requisições do curso entre origens. Nem a URL /lab do Jupyter nem localhost:5000 podem ser acessados pela página do curso. O proxy CORS hospedado fica restrito ao modo LMS/iframe estático com o endpoint padrão.

Como explorar o material

A ordem dos módulos oferece um caminho guiado, mas cada página também funciona de forma independente. No percurso completo, cada módulo aproveita o anterior: o ciclo executado no navegador se torna um workflow de escopo controlado; esse workflow passa para um runtime de agente persistente; e o alcance maior do runtime justifica o limite imposto pelo sistema operacional. Comece pela tarefa relevante para você. Cada página termina em um artefato ativo e mantém o código de suporte disponível. Você pode alterar os exemplos no navegador, hospedá-los por conta própria ou fornecer este repositório como contexto a um agente de código.
