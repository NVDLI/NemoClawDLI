scripts/build packaging and deploy helpers

Build and publishing helpers for the static bundle, branch manifests, language manifests, hooks, and edX export.

Some build commands write generated output. Use temporary output paths for checks unless you intend to update release artifacts.

Linkage map

build_pages.shsite assembler. Builds public/ from the client-side course and validation assets. project_docs_explorer.pydocs graph and projection gate. Rejects unlisted or orphaned authored docs, ambiguous generated files, and missing artifact targets. project_source_tree.pyAuthoring-source projection for complete, working SKILL explorers in Pages; maps dot-prefixed host configuration to public-safe routes and rebuilds generated standalone output only at its canonical route. project_artifact_navigation.pyArtifact-root projector. Rebases generated navigation and supplies a working directory entry for every shipped SKILL contract. project_artifact_manifests.pyArtifact manifest projector. Keeps branch, language, and license evidence aligned across every discovered source mirror. vendor_browser_dependencies.mjsbrowser dependency packager. Generates same-origin bundles, licenses, hashes, and source references from the exact lock. bundle_standalone.pystandalone bundler. Copies and inlines the course into a self-contained web bundle. push_pages.shPages pusher. Pushes the assembled public/ output to the Pages target. publish_edx.pyedX export. Creates the iframe-friendly edX surface. install-hooks.shhook installer. Writes shared dispatchers that run the active worktree's repository gates. build_branch_manifest.pybranch manifest. Lists only production and preview paths published in the current Pages artifact. build_language_manifest.pylanguage manifest. Builds language-branch metadata for translated bundles. package_release.pydeterministic release packager. Builds the versioned archive, manifest, release assets, checksums, and required external-evidence list. build_security_review_package.pySecurity review design composer. Produces one compact, self-contained design and deterministic two-file upload archive.
