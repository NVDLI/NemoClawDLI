scripts/runtime link and browser runtime

Runtime-facing tooling: the single JavaScript link engine, the browser topology viewer, and the thin Python and shell shims that run the same engine in CI.

Browser checks run with host Node.js, the pinned playwright-core API, and an installed Chromium or compatible Chrome. Start with scripts/runtime/browser_env_probe.sh. Python tooling requires 3.11 or newer; 3.12 is the tested default. Use a virtual environment and pinned locks. External isolation is operator-owned.

OpenClaw fallback

Pass these values from the host when a live check requires them:
  • CLAW_ACCESS_PROVIDER
  • CLAW_ACCESS_SESSION
  • OPENCLAW_CORS_PROXY_BASE
Keep Cloudflare Access and Pomerium values in the process environment only.
