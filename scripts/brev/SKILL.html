Brev course delivery

A NemoClaw Brev launchable serves the same built Pages site that GitHub Pages publishes, under the /dli/ path beside its agent. The course then shares the agent's origin, so it reaches the launchable with the browser's own Secure Link session instead of a pasted access cookie. The GitHub Pages deployment and its build are unchanged.

The launchable's image supplies NemoClaw, OpenShell, nginx, and every package. The startup script that runs route.sh on a new launchable stays outside the repository. This directory adds configuration and shell only.
