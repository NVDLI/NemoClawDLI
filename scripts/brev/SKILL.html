Brev course delivery

Brev serves the same built Pages site that GitHub Pages publishes, under the /dli/ path. On a NemoClaw launchable, the course then shares the agent's origin, so the course reaches the launchable with the browser's own Secure Link session instead of a pasted access cookie. The GitHub Pages deployment and its build are unchanged.

Container images, packages, and toolchains for this delivery live in the operator's Compose file, which stays outside the repository. This directory adds configuration and shell only.
