Quick reference

Run these in the VM terminal. Each Run button pastes the command there, with your sandbox name in place of <name> once you have an agent.

Inspect

nemoclaw list
Sandboxes on this launchable and the agent in each.
nemoclaw <name> status
Health of one sandbox, its gateway, and its inference route.
nemoclaw <name> logs --follow
Stream the sandbox log while you run an exercise.
nemoclaw <name> connect
Open a shell inside the sandbox to see what the agent sees.

Network policy

openshell term
Watch the sandbox live. Run an exercise again and inspect the request that policy blocked.
nemoclaw <name> policy list
The sandbox's current policy, including the presets it uses.
nemoclaw <name> policy add <preset> --dry-run
Preview a preset's endpoints. Drop --dry-run to apply it.
nemoclaw <name> policy remove <channel>
Withdraw access you added.

Models

nemoclaw inference get
The provider and model the agent uses now.
nemoclaw inference set --provider <provider> --model <model>
Switch the agent's model. NemoClaw tests the route from the sandbox before it commits the change.

Recover

nemoclaw <name> doctor
Diagnose a sandbox that stopped answering.
nemoclaw <name> gateway restart
Restart the agent gateway after a configuration change.
nemoclaw <name> recover
Re-run the sandbox readiness checks and restore its dashboard forward.
