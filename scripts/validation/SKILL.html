scripts/validation deterministic gates

Static and rendered validators enforce links, layout, prose, code hygiene, figures, cells, theme behavior, screenshots, and course contracts.

Run commands from the repository root. Root-level script paths remain compatibility entrypoints; implementation files live in this directory tree.
Use the shared gate for branch evidence. The focused commands below diagnose individual contracts or exercise browser behavior. Visual changes also require a served page, screenshot evidence, and review in the active harness.
