scripts/materials reference material tooling

Material vendoring and indexing tools for curated course references, glossary data, RAG indexes, and CLI readmes.

Every shared gate verifies committed snapshots, manifest metadata, character counts, and full SHA-256 values without network access. Live checks add bounded retries; only production-ref pushes may tolerate classified transient reachability.
