CORS relay contracts

The compact workers define the browser contract expected from model and NemoClaw relays. The launchable relay binds each Cloudflare Access or Pomerium session to its matching Brev host family. The deployable projection supplies the full Lambda, CloudFront, generic infrastructure-template, smoke-test, and unit-test implementation without environment identifiers or provisioning dependencies.

Run commands from the repository root. This repository publishes optional middleware source; credentials, state, DNS, resource names, and operated deployments remain outside it.
