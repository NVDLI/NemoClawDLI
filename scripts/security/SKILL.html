Linkage map

audit_iframe_proxy_opt_in.pyModel endpoint and iframe relay audit. Checks explicit persistence, credential destination warnings, default-only iframe proxying, billing headers, and hosted endpoint contracts. audit_cors_proxy_projection.pyRelay source projection audit. Verifies manifest membership and hashes, Apache-2.0 headers, dependency-free runtime source, parameterized infrastructure, and the absence of operator environment identifiers. iframe_proxy_worker_findings.mdhosted relay reference findings. Separates repository client-contract fixtures from the externally maintained deployment. audit_python_dependencies.pydependency vulnerability floor audit. Checks tracked Python declarations against PyPI/OSV metadata, exact workspace pins, and retired direct dependencies. audit_vulnerability_waivers.pysecurity exception audit. Validates opaque fingerprints, ownership, executable controls, scope, and expiry. audit_dependency_locks.pydependency lock audit. Enforces exact Python 3.11 closures, direct-manifest parity, and absence of retired runtime components. audit_sbom_policy.pyruntime SBOM policy audit. Proves lock coverage, rejects retired components, and reports whether license metadata is SPDX, named, or absent. audit_codeql_sarif.pyFails on new authored CodeQL findings and on any disposition whose stable line identity, artifact bytes, evidence, controls, or expiry drifted. audit_github_code_scanning.pyFails when the exact commit's host-owned CodeQL check is absent, pending, or red, or when the pull-request merge ref retains an open alert. codeql-vendor-dispositions.jsonTime-boxed public policy bound to CodeQL rule, path, start location, primary line hash, and exact reviewed bytes. It is not a pattern waiver. sbom_evidence.pyVerifies the committed catalog and emits commit-bound manifests plus reconciled license appendices from CI SBOMs. run_full_sca.pySCA and SBOM runner for the installed Python validation environment and repository source. vulnerability-waivers.jsonfingerprinted exception registry. Public metadata never republishes private finding details. dependency_security.mdstandard integration path for fast source checks, waiver policy, SBOM output, full SCA scans, and GitLab Dependency Scanning.
