# Activity browser source provenance

`activity-sdk.js`, `_activity.js` and `_activity_runtime.js` are NVIDIA-authored, hand-maintained browser JavaScript under the repository Apache-2.0 license. Courses import this ES module directly; it is not a packaged or generated SDK distribution. Course milestone definitions and producer evidence are authored in `docs/ACTIVITY_MILESTONES.md`. The build projects its structured definitions to `web/activity/activity_milestones.json`. The course adapter supplies the config URL at session initialization alongside consent policy. The shared client loads and validates this JSON, copies local definitions, scopes sessions to that configuration, and binds configured success events to real page targets. Session creation transmits only the published artifact identity fields; milestone definitions stay local. The SDK contains no course-specific definitions or event names.
