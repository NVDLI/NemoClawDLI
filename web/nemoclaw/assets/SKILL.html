Image provenance

Theme-aware course diagrams follow the toggle. Paper conversions render on white because the lessons display them that way. Each card also shows the content origin, transparency class, and whether a visible AI-content disclosure is required.

Directory policy. Image assets live in assets/figures/. Root assets/ is reserved for indexes, CLI readme snapshots, and favicon/support files. Asset provenance belongs in this page and in source comments; course pages should describe the concept, not implementation history or review shorthand. Keep meaningful labels inside diagrams, but move captions and provenance out of SVG-rendered text. Any agent that touches an image or its page placement must preview the rendered result through its host harness, inspect light and dark mode when relevant, activate the narrow-width lightbox and verify readable panning/close behavior, show the requester the evidence, and report any exact blocker.
