Course runtime scripts

These modules support the browser course pages. Page HTML imports scripts/_shared.js; that module re-exports page-facing APIs and delegates larger subsystems to smaller siblings. studio.html lists checks operators can run or copy. Before browser validation, run scripts/runtime/browser_env_probe.sh to verify host Node.js, the pinned Playwright API, and Chromium.

Use style

InterfaceUse styleTest focus
Course pagesImport scripts/_shared.js from lesson HTML. Keep lesson markup readable, with runtime behavior behind named helpers.Layout links, bundle gate, page audit.
Canvas flowsUse mountCanvasFlow or mountRunCell. Code starts collapsed unless the code itself is the lesson artifact.Cell audit, canvas HTML validation, runtime page harness.
Learning viewsUse open details.learning-block only for optional narrative. Supply a stable id, subtle text-backed scope cue, local inline question, and body wrapper. Guided is the first-visit default and collapses interactive code while retaining each cell's local disclosure. Keep prerequisites, exercises, warnings, and safety limits outside every tier.Learner-flow static mutation suite plus source and built browser lifecycle.
OpenClaw controlsUse _connection.js for every launchable HTTP or WebSocket route and _openclaw.js for probes, chat, logs, and recovery. Cloudflare metadata uses its tab-scoped relay session. Both providers keep WebSockets in the signed-in browser; Pomerium also uses openclawLoopbackProbe for the two fixed metadata reads. Do not rebuild routes in lesson cells.Connection routing contract plus browser runtime harness.
Chat and retrievalUse explicit model/key/proxy state through shared helpers. Static pages must not add hidden key paths or private service assumptions.Security audit plus ship gate.
StudioUse studio.html as the authoring and test console. Read-only static preview supports inspection, comments, references, Light export review, and host-native test commands. Lab authoring enables Jupyter contents writes only when the host supplies that API.python3 scripts/validation/studio_interface_audit.py; browser harness commands below.

Helper notebook

This runnable notebook samples the helper families exposed to course cells. It is deliberately safe in static preview: local helpers run immediately, while model, browser-network, and OpenClaw helpers first check the available key or launchable state and log what would run next.
