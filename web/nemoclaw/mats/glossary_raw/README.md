# glossary_raw — vendored NVIDIA glossary pages (read critically)

This directory holds the NVIDIA glossary pages the course leans on, vendored as
Markdown with their images. It gives the curated [`../nvidia_agent_glossary.md`](../nvidia_agent_glossary.md)
a primary source behind every entry and keeps the bundle from depending on a live
fetch. Each `<slug>.md` is generated by [`../../../../scripts/materials/vendor_glossary.py`](../../../../scripts/materials/vendor_glossary.py);
`_versions.json` logs the source URL, fetch date, content hash, and image list for
each page, so a re-run shows exactly what drifted.

## These are marketing projections, not ground truth

Every page here is NVIDIA glossary or product copy. That genre is a projection of
the truth shaped by what the page is selling, and it is flawed by nature in
predictable ways. Name them before you cite anything:

- **Simplified past the point of accuracy.** A glossary entry compresses a
  contested, fast-moving research area into a few confident sentences. The
  compression is the product; the caveats and failure cases are what got cut.
- **Market-speak.** Terms are defined to fit the catalog (NIM, Nemotron,
  Blueprints, OpenShell), so a definition often doubles as positioning for a
  product rather than a neutral account of the idea.
- **Market momentum offered as validation.** Adoption, scale, and "the new digital
  workforce" framing stand in for evidence. Popularity is not correctness.
- **Antithesis-driven.** The shape is usually "old thing limited, new thing
  capable" (generative vs. agentic, shallow vs. deep). The contrast is real but
  sharpened for effect, and the boundary is fuzzier than the page admits.
- **Argument derived from a desired conclusion.** The page starts from "agents are
  the future" and reasons backward to support it, instead of weighing where the
  claim actually holds and where it does not.

So treat each file as a faithful record of how NVIDIA frames a term, and nothing
more. For the grounded reading, use the curated glossary's *In the course* lines
(what the term means once you build it) and the papers in
[`../agent_field_guide.md`](../agent_field_guide.md). Where this folder and the
field guide disagree, the field guide wins.

## How it is produced

```bash
pip install requests beautifulsoup4 markdownify lxml
python3 scripts/materials/vendor_glossary.py                 # the default TERMS list
python3 scripts/materials/vendor_glossary.py generative-ai    # add a specific slug
```

The script extracts the page's main article, strips the site chrome (header, nav,
footer), downloads the content images into `images/` and rewrites the references to
them, and records the run in `_versions.json`. Images injected purely by
client-side JavaScript are not in the fetched HTML and are not captured; the hero,
diagrams, and SVG figures that ship in the static markup are. YouTube posters are
left as external links rather than vendored.
