Course styles

Course pages link styles/_style.css. The standalone builder inlines that file and appends styles/_lite_overlay.css for the light iframe export.

FileRole
_style.cssBase course theme, layout, topbar, key panel, non-splitting runnable-cell action groups, diagrams, cards, and dark/light token sets.
_lite_overlay.cssLight export overlay for iframe delivery and studio preview comparison.
